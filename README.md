# Sugar Rush 🍭🏎️

Juego de carreras de karts en Unity inspirado en el circuito de Sugar Rush de *Wreck-It Ralph* (*Ralph el demoledor*).

- Unity 6000.3.25f1 LTS · URP
- Abrir la carpeta del proyecto desde Unity Hub (**Add → Add project from disk**).

> Proyecto de fan sin fines de lucro. Sugar Rush y sus personajes son propiedad de Disney. Los modelos 3D son de sus autores en Sketchfab bajo licencia CC Attribution, ver [CREDITS.md](CREDITS.md).
