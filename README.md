# Sugar Rush 🍭🏎️

Juego de carreras de karts en Unity inspirado en el circuito de Sugar Rush de *Wreck-It Ralph* (*Ralph el demoledor*).

- Unity 6000.3.25f1 LTS · URP
- Abrir la carpeta del proyecto desde Unity Hub (**Add → Add project from disk**) y darle Play en la escena `MainMenu`.

## Controles
| | Teclado | Control |
|---|---|---|
| Acelerar / frenar | W S / ↑ ↓ | RT / LT (o A) |
| Girar | A D / ← → | Stick izquierdo |
| Drift (suelta para turbo) | Espacio / Shift | RB / X |
| Volver a la pista | R | Y |
| Pausa | Esc | Start |
